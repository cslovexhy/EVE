# EVE

Empire vs Empire — a guild war strategy game inspired by Underworld Empire's EvE system.

## Status

Early research phase. Gathering reference material and defining core mechanics.

## Reference Material

- `docs/reference_ue_eve.md` — Parsed mechanics from Underworld Empire's Empire War system
- Source: https://underworld-empire.fandom.com/wiki/Empire_War

## Core Concepts (from UE reference)

- Two guilds (empires) battle head-to-head
- 3×3 grid of buildings per side
- Token-based action economy
- Player classes with unique combat roles
- Positional visibility/fog of war
- Building upgrades and super powers
- 2-hour timed matches with point-based victory
